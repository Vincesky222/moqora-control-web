# MOQORA Control

PWA mobile interne pour piloter MOQORA.

## Fonctionnalités V1
- Accueil / score santé
- Social Growth
- Analytics / UTM
- Réseaux
- Catalogue
- Synthèse Agent
- Installation PWA iPhone / Android
- Offline minimal via service worker

## Important
Les métriques visibles dans la V1 sont des données de démonstration tant que Metricool et Clics ne sont pas branchés à un backend sécurisé.
Ne jamais exposer de clé API directement dans le navigateur.
